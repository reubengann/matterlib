# matterlib

`matterlib` provides symbolic mathematics helpers and Jupyter animation tools
for the Theory of Matter course.

## Examples

- [2D animation examples](examples/anim2d.md)
- [3D animation examples](examples/anim3d.md)

## Public modules

- [`matterlib.anim2d`](reference/anim2d.md) provides ipycanvas animation
  controls.
- [`matterlib.anim3d`](reference/anim3d.md) provides k3d animation players and
  helpers.
- [`matterlib.symbolic`](reference/symbolic.md) provides equation and
  constrained-partial helpers through `matterlib.spp`.
- [`matterlib.thermo`](reference/thermo.md) provides standard thermodynamic
  partial derivatives.

The API reference is generated directly from the Python source, so signatures
and public members stay synchronized with the package.
